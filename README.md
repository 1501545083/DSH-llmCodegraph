# LLM 代码知识图谱（llm-codegraph）

DSH 动态 Cordis 插件的开发版源码。插件读取一个代码目录，用 LLM 逐文件分析符号与调用关系，生成 2D 知识图谱（节点绑定 文件+精确行号），支持文件修改监听实时更新、调用图/业务图双视图。

## 文件说明

| 文件 | 说明 |
|---|---|
| `host.js` | 宿主端：目录扫描、LLM 分析（分块+行号前缀提示词）、符号/调用边解析、业务流 BFS、RPC 接口、宿主工具（codegraph_query / codegraph_analyze / codegraph_dump）、3s 监听轮询 |
| `client.js` | 浏览器端：「代码图谱」标签视图，力导向/分层布局、碰撞避让、方框节点（名称+摘要）、有向箭头、节点拖拽、缩放平移、模型选择 |
| `render-test.html` | 独立渲染测试页：用真实图谱数据在纯 HTML 中验证 SVG 渲染效果（不依赖 DSH） |

## 运行方式

本插件是 **DSH 动态 Cordis 插件**（进程内定义、不持久化，进程重启后丢失），源码本身不直接运行。部署需在当前 DSH 会话中：

1. 用 `cordis_define` 定义新包（code.host = host.js 内容，code.client = client.js 内容）
2. 用 `cordis_run` 激活

或通过对话让助手完成 `cordis_define` / `cordis_run` 挂载。

## 功能特性

- **LLM 分析**：逐文件发送带 `N|行号` 前缀的源码，要求返回结构化 JSON（符号 + 调用列表），行号精确绑定；温度 0；大文件自动分块（500 行/50 行重叠）
- **调用图**：全部符号 + 已解析的调用边，力导向布局
- **业务图**：从入口（无入度且有出度的符号）BFS 向下游扩散，默认合并展示全部业务流，可下拉单选单入口
- **监听修改**：3 秒轮询，文件变更自动重分析、删除自动清理、新增自动入队
- **交互**：节点左键拖拽（箭头实时跟随）、滚轮缩放、空白拖拽平移、搜索高亮、详情面板、模型可配置

## 关键 RPC

| 方法 | 作用 |
|---|---|
| `get-state` | 状态（目录、分析进度、模型、日志） |
| `set-root` / `set-watch` / `set-model` | 设置目录 / 监听开关 / 分析模型 |
| `analyze` | 入队分析（force 全量） |
| `get-graph` | 图谱载荷（mode: call/business，entry 可选） |
| `get-symbol` | 符号详情（调用者/被调者/未解析） |
| `get-model-options` | 可用 provider/model 列表 |

## 版本历史

当前运行版本：**pkg-21**（动态插件 `cgll-2`，共 21 个不可变包，pkg-5 ~ pkg-21）。

- pkg-18：业务图合并全部入口
- pkg-19：方框节点（名称+摘要）+ 有向箭头
- pkg-20：节点拖拽 + 初步避让
- pkg-21：布局空间随节点数动态放大，修复避让算法顺序 bug（消除重叠）
